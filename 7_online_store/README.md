# Интернет-магазин Megano

Бэкенд-часть для интернет-магазина Megano. Проект предоставляет RESTful API для взаимодействия с готовым фронтендом,
позволяя пользователям просматривать каталог товаров, управлять корзиной, оформлять заказы и взаимодействовать со своим
профилем.

## Стек технологий

* **Язык программирования:** Python 3.11
* **Веб-фреймворк:** Django, Django REST Framework
* **База данных:** PostgreSQL
* **Инфраструктура:** Docker, Docker Compose

## Особенности архитектуры и реализации

* **Гибридная корзина:** Для неавторизованных пользователей данные корзины хранятся в сессии. При авторизации или
  регистрации происходит автоматический перенос товаров из сессии в базу данных.
* **Оптимизация запросов:** Решена проблема N+1 запросов при выдаче каталога и истории заказов с помощью
  `select_related` и `prefetch_related`.
* **Отказоустойчивое API:** Настроены кастомные парсеры (`PermissiveJSONParser`) для обработки нестандартных запросов от
  клиентской части (без заголовков `Content-Type` или с некорректным JSON).
* **Интеграция фронтенда:** Клиентское приложение собирается в `sdist` и устанавливается внутрь виртуального окружения
  Docker как полноценный Python-пакет (`diploma-frontend`).
* **Управление медиа:** Имплементирован `django-cleanup` для автоматического удаления старых файлов и изображений при их
  обновлении или удалении записей.
