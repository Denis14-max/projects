# Telegram-бот для поиска отелей

Телеграм-бот позволяет искать отели по всему миру, фильтровать их по цене, просматривать фотографии и сохранять
понравившиеся варианты в личные заметки с напоминаниями.

В качестве источника данных используется открытое API `Booking.com` (через сервис RapidAPI). База данных реализована на
PostgreSQL с использованием ORM Peewee.

## Функционал

* **Умный поиск:** Поиск городов и отелей с использованием интерактивного календаря для выбора дат.
* **Фильтрация и сортировка:** `/lowprice`, `/highprice`, `/bestdeal`.
* **Пагинация карточек:** Удобный просмотр результатов с помощью кнопок "Вперед/Назад".
* **Система заметок:** Возможность сохранить карточку отеля в базу данных и установить дату/время напоминания.
* **История запросов:** Команда `/history` выводит историю поиска с возможностью повторно просмотреть найденные отели
  без нового запроса к API.

## Установка и запуск

1. Клонируйте репозиторий.
2. Активируйте виртуальное окружение и установите зависимости: `pip install -r requirements.txt`
3. Создайте файл `.env` в корне проекта и добавьте следующие настройки:
   * `BOT_TOKEN` — токен вашего Telegram-бота.
   * `RAPID_API_KEY` — ключ доступа к [Booking.com API](https://rapidapi.com/DataCrawler/api/booking-com15/) на платформе RapidAPI.
   * `DB_NAME` — имя вашей базы данных PostgreSQL.
   * `DB_USER` — имя пользователя базы данных.
   * `DB_PASSWORD` — пароль базы данных.
   * `DB_HOST` — адрес сервера БД (например, localhost).
   * `DB_PORT` — порт сервера БД (по умолчанию 5432).
4. Запустите бота командой: `python main.py`

## Структура базы данных

* `User` — хранение telegram_id пользователей.
* `Note` — хранение заметок и текстов напоминаний.
* `SearchHistory` — сохраненные результаты поиска.
