# Корпоративный сервис микроблогов

Бэкенд-часть для внутреннего корпоративного сервиса микроблогов, по функционалу похожего на Twitter. Проект
предоставляет RESTful API для взаимодействия с готовым фронтендом, позволяя пользователям публиковать записи,
обмениваться лайками и формировать ленту новостей на основе подписок.

## Стек технологий

* **Веб-фреймворк:** FastAPI
* **База данных:** PostgreSQL (через асинхронный драйвер `asyncpg`)
* **ORM и Миграции:** SQLAlchemy, Alembic
* **Инфраструктура:** Docker, Docker Compose

## Реализованный функционал

* Создание новых твитов с опциональным прикреплением изображений.
* Удаление собственных твитов.
* Система оценок: возможность ставить и убирать отметку «Нравится».
* Социальные связи: подписка на других пользователей и отписка от них.
* Формирование персонализированной ленты: отображение твитов только от тех авторов, которых читает пользователь, с
  сортировкой по убыванию популярности (количеству лайков).
* Просмотр информации о профилях пользователей (подписки и подписчики).

## Документация API

Все ответы сервиса и доступные эндпоинты задокументированы с помощью Swagger.
Документация становится доступна автоматически после запуска проекта по адресу: `http://127.0.0.1:8080/docs`.
Аутентификация в Swagger и в самом приложении реализована через передачу ключа в HTTP-заголовке `api-key`.

## Инструкция по запуску

Проект упакован в контейнеры и легко разворачивается с помощью Docker. База данных и все необходимые
таблицы инициализируются автоматически при запуске.

1. Убедитесь, что у вас установлены Docker и Docker Compose.
2. В корневой директории проекта выполните команду:
   ```bash
   docker-compose up -d --build
